Step 1: Understanding AI, ML, and Deep Learning

🔹 What is Artificial Intelligence (AI)?

AI is the science of creating machines that can think and act like humans.
It includes rule-based systems, automation, decision-making, and learning-based models.

✅ Real-World Example: Virtual Assistants (Alexa, Siri, Google Assistant)

AI-powered assistants can understand voice commands, respond intelligently, and learn from interactions.

🔹 What is Machine Learning (ML)?

ML is a subset of AI that enables machines to learn from data without being explicitly programmed.

✅ Real-World Example: Netflix Recommendation System

Netflix learns user preferences based on watch history, ratings, and behavior.
It applies ML algorithms to suggest content users might like.
👉 ML helps Netflix personalize recommendations, increasing user engagement.

🔹 Difference Between AI, ML, and Deep Learning
Concept	Definition	Real-World Example
AI (Artificial Intelligence)	Machines that mimic human intelligence.	Virtual Assistants (Alexa, Siri)
ML (Machine Learning)	Machines learn from data to make decisions.	Netflix Recommendations
Deep Learning (DL)	ML with neural networks for complex tasks.	Face Recognition in iPhones
✅ Example: Self-Driving Cars

AI enables the car to navigate and make driving decisions.
ML helps it learn from previous driving experiences.
Deep Learning processes real-time camera data to recognize objects (pedestrians, traffic lights).
